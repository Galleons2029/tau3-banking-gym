## 已确认根因

Gemini 的异议称：KB 中没有邮箱修改工具与普通身份验证方法，因此任务不可公开求解。
实际捕获的教师初始上下文中，`change_user_email` 和 `log_verification` 都是公开工具，
系统策略也明确包含邮箱修改前的身份验证及验证日志要求。旧审核输入只给了业务文档、
候选资料和 unlock 返回，遗漏了常驻工具集合和系统策略。

证据绑定在父版 `public-admission-context-diagnosis.json`：原始 capture 的 SHA256、
实际工具名及系统策略均可核查。父版异议保留，不直接改写成通过。

## 修复与恢复规则

准入审核现在同时接收教师真实捕获的系统消息和工具 schema，以及实际解锁回包。
常驻公开工具不要求额外 KB 文章或 unlock。抽取器只复制系统消息和工具定义，
不混入用户私有模拟器提示、对话内容、assistant reasoning 或评分意见。

对完全未变化的父试跑任务，可以复用原有的双模型正向准入证明，条件包括：

- 父任务已有有效准入证明，业务问题、用户场景、种子和公开数据匹配。
- 源码差异仅限本次审核编排和恢复模块；业务运行时、生成器、验证器、公开文档和 schema 不变。
- 静态检查完全一致，当前盲解确实来自原 capture 的严格回放；原回包及结果 hash 匹配。
- 回放后的完成状态、环境成功与独立义务结果和原记录相同；正向审核结论逐项为 true。

复用来源写入 `admission_review_origins`，不伪装为新的模型审核。无证明、业务变化、
新采样、运行时变化、结果变化或回包篡改均不能复用。原盲解失败并不自动否定任务；
只有其任务准入证明为有效，且失败记录原样保留时才可复用。

教师质量审核与导出证据绑定继续执行。四个固定 seed、全部合格轨迹输出、累计预算、
GLM 教师/Gemini 用户与审核、合计 256 并发上限均保持原配置。
