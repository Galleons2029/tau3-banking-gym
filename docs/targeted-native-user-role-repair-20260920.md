# 用户模拟器角色约束与旧 SFT 清理

## 范围

本次修改由用户授权：在 user LLM system prompt 中强调不要扮演客服，测试效果，并修复或舍弃已有问题轨迹。采用整条舍弃；保留原始采样和审核证据，不编辑用户话术后拼接原教师响应。

## 实现

- `src/tau3/user/role_guard.py` 定义 `customer_role_v1`（详细版）和 `customer_role_v2`（简短版）；只在原 system 文本末尾追加一段角色约束，不改 API role、历史消息、工具、seed 或温度。
- `UserSimulator(customer_role_guard="customer_role_v2")` 启用简短版；NativeConfig 的 `user_role_guard: "customer_role_v2"` 在新运行中启用。`True` 和 `customer_role_v1` 保留详细版。默认关闭，已冻结运行不修改。
- `native/user_roles.py` 对每条用户文本逐回合审核，必须覆盖全部编号，拒绝不存在的证据引用；GLM 和 Gemini 独立审核，均通过才可进入可用集。确认串角色整条丢弃；分歧、模糊结论、基础设施失败隔离。
- 新版启用角色约束的 native 质量准入在既有质量审核之外执行角色审核，环境成功和后续纠正不能覆盖早先的角色错误。

## 对照实验

固定 48 个原始请求：28 个旧筛查候选、4 个新发现的明确错误、8 个普通开场、8 个用户工具结果回合。每个请求分别执行原提示词和仅追加角色约束的提示词，共 96 次用户生成。全部沿用原请求 seed、temperature=0、工具及上下文。两模型独立审核生成内容；空输出、截断、仅工具调用等不能按完整客户文本通过。该集合富集问题案例，不代表总体错误率。

## 旧数据

对 repair8 正式集全部 890 条真实轨迹逐条双模型复审；保留行按源文件原始字节输出，另存丢弃与隔离行和源行映射。旧的 3000 行重复上采样包继承源数据问题，不能绕过这次清理。新数据包不靠重复行凑够 3000。角色清理通过仅代表该项审核通过，不重新宣称所有其他维度均经本次复核。

## 执行与预算

脚本：`scripts/repair_targeted_user_roles.py`。独立诊断运行时来自 expand3k-v1 冻结版本，仅增加角色约束与审核模块。所有线上调用记入原扩量轮累计预算，共享 256 物理请求并发池，不计作教师采样槽位，不改原四次 seed。

产物：`data/synthesis/targeted-native-v03-r10-expand3k-v1/verification/user-role-repair-v1/`。

- `probe-plan.json` / `probe-results.json`：固定实验条件、响应和独立审核。
- `row-reviews/`：逐条原始轨迹双模型审核证据。
- `filtered/`：可用 SFT、丢弃和隔离数据、映射与哈希清单。

第一版 48 对请求的双模型审核结果：原提示词 40 通过、4 串角色、4 空回复；追加角色说明后 39 通过、6 串角色、3 空回复。未观察到改善，不能据此宣布角色错误已解决。简短版复用已记录基线，在相同案例和 seed 上测试，结果为 43 通过、4 串角色、1 空回复。角色错误数与基线一致；两版都不应被视为已解决串角色。保留简短版作为可选防护，新的严格角色审核负责阻断错误轨迹。

回归：153 项 native 相关测试通过；随后补充的角色准入阻断测试在 9 项角色测试中通过；修改文件 Ruff 检查通过。全量 1780 份模型判定完成；765 条保留，114 条舍弃，11 条隔离。保留数据覆盖 290 个 task。原筛查的 107 条候选全部排除（105 舍弃、2 隔离），另发现 9 条此前未被词法筛查发现的串角色轨迹。

导出验收 `PASS_ROLE_FILTER_EXPORT`：所有源行恰好进入一个分区，保留行逐字节一致，两模型覆盖全部用户回合，工具配对与训练格式转换通过。旧 3000 行重复包有 366 个舍弃副本、39 个隔离副本；旧包及原 main 已写入 `USER_ROLE_FILTER_STATUS.json` 和停用说明，原文件保留为证据。

可用文件：`filtered/sft.jsonl`（native）及 `filtered/general_agent_reasoning.jsonl`（general-agent），均为 765 条真实唯一轨迹，未重新上采样到 3000。

本次新增物理调用 2223 次：原提示词生成 48 次、两版新提示词共 96 次、角色审核及重审 2079 次；均进入原轮累计预算。教师采样槽位未增加（仍为累计 1900），没有用诊断请求替换教师 seed。旧 supervisor 保持教师采集前的受控暂停；角色修订需要新的冻结运行版本，不能把诊断成功直接视作旧运行已采用新提示词。
